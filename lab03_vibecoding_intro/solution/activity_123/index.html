Grocery Prices — Aldi, Kroger, Publix, Trader Joe's, Walmart

Line charts compare prices for five items across four years: 2010, 2016, 2022, and 2025. Drop groceries_all.csv in the same folder, then click “Load CSV”. If your browser blocks local file loads, use the file picker.

Tip: If you open this file directly in a browser as file://, the “Load CSV” button may be blocked by CORS. In that case, either use the file picker or run a local server (e.g., python -m http.server) in the folder.
